# Famiglia Pizza Online

Crie um site moderno, elegante, responsivo e profissional para a pizzaria Famiglia da Pizza, localizada em Belém – PA.

OBJETIVO DO SITE

O site deve funcionar como a página oficial de divulgação da pizzaria, apresentando a marca, ambiente, pizzas, cardápio completo, avaliações, localização, contato e sistema de reservas.

O design deve transmitir uma sensação de pizzaria tradicional, familiar, aconchegante e, ao mesmo tempo, moderna e premium.

O site deve ter duas áreas principais separadas no menu:

Cardápio — página exclusiva com todo o cardápio.

Reservas — página exclusiva para o cliente solicitar uma reserva.

Não invente informações que não foram fornecidas.
